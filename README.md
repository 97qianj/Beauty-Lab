# Qian Jiang · UX & Product Design

English portfolio and three case studies. Each case includes screenshots from the
14-page PDF and a browser-based experience.

- **Mymee** has a sample wardrobe and an outfit board with editable position, size, and layer order. Sample styling suggestions are prebuilt. One look can be saved in browser storage.
- **Nailed It!** has a per-finger editor with a hand model, coat and finish controls, decoration, and an adjustable magnetic highlight. One set can be saved in browser storage. The catalog and renderer are simplified for the web demo.
- **The Four of Us** uses the original illustrated shelf and 30-page bilingual reader. Read-aloud uses browser speech synthesis.

## Local preview

Run `python3 -m http.server 8000` from this directory and open
`http://localhost:8000/`.

## GitHub Pages

The files in this directory belong at the root of `97qianj/Beauty-Lab`.
The Pages source is `main` and `/(root)`. The site uses relative local
paths and needs no build step.

## Assets

Case study screenshots were taken from the supplied portfolio. Wardrobe
samples are from `2026/Mymee/ootd-test-images`; the hand model is from
`2026/Nail_design/手模原图`. The shelf and reader come from
`2026/picture-books`, with images optimized as WebP for the web.
