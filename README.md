# Qian Jiang · UX & Product Design

An English portfolio website with three browser-local demos. The 14-page PDF is available for viewing and download.

## Local preview

Open `index.html` in a browser, or run `python3 -m http.server 8000` from this directory.

## GitHub Pages

The files in this directory belong at the root of `97qianj/Beauty-Lab`. In **Settings → Pages**, select **Deploy from a branch**, then choose **main** and **/(root)**. The site uses relative paths for its local assets and needs no build step. The `.nojekyll` file enables static serving.

## Assets

- Portfolio PDF, cover, and project screenshots from the supplied portfolio.
- Wardrobe samples from `2026/Mymee/ootd-test-images`.
- Story excerpt and illustrations from `2026/picture-books/Stories/who-will-turn-off-the-light`.
